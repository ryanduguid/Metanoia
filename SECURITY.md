# Security Policy

## Scope

This repository is the GitHub profile repository for `@ryanduguid`. It contains
profile documentation and the two checks that test it (banner-check and
link-check). It does not distribute application code, packages, deployed
services or credentials.

Security reports about a project linked from this profile belong in that
project's own repository. Use its `SECURITY.md` or GitHub private vulnerability
reporting channel so the report reaches the maintainers of the affected code.

## Reporting a concern about this repository

Use GitHub's **Report a vulnerability** option in this repository's Security
tab. Please do not disclose potential security issues, credentials, personal
information, or client information in a public issue.

Include the affected profile content, a clear description of the concern, and
safe reproduction or verification details where applicable. Reports are
assessed according to their impact and this repository's documentation-only
scope.

## Out of scope

Issues in third-party services, GitHub itself, or a linked project that has its
own repository are out of scope here. They should be reported to the relevant
maintainer or vendor instead.
